## VSCODE Extension Development Intellisense And Project Steps
### How to Add Configuration on launch.json file (VSCODE Theme Extension)
1. Open .vscode folder and then open launch.json file
[![VSCODE Intellisense And Project Tutorial](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial.gif)](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial.gif)
2. Click "Add Configuration"
[![VSCODE Intellisense And Project Tutorial 2](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial-2.gif)](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial-2.gif)
3. Press up arrow on your keyboard until you see `VSCODE Theme Extension Development(Preview VSCODE Theme Extension)` and then press enter
[![VSCODE Intellisense And Project Tutorial 3](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial-3.gif)](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial-3.gif)
4. and now your launch.json intellisense has been created

1. Open .vscode folder and then open launch.json file
[![VSCODE Intellisense And Project Tutorial - Change Configuration Name](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial.gif)](https://raw.githubusercontent.com/amiralariska/vscode-extension-development-intellisense-and-project/refs/heads/vscode-extension-development-intellisense-and-project/vscode-extension-development-intellisense-and-project-tutorial/vscode-extension-development-intellisense-and-project-tutorial.gif)
